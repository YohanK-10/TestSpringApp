## Interpretation boundary

This report measures fill, constraint consistency, rotation, coverage, diversity, and latency. It does **not** establish human semantic relevance. The mood values are generated by the same rules used by the ranker and are therefore circular guardrails. Human/AI-assisted graded labels remain a later, separately versioned phase.
